# ARC-Adaptive-Routine-Coach
Adaptive workout application with real time workout adjustments and AI coaching.

## ARCs Current Implementation
Current version includes:
-User profile page
-Daily readiness check
-Spring Boot backend
-H2 Database
-User profile data storage
-Readiness data storage

Other features like workout generation, ORIN AI implementation, workout history, and other features are still being worked.

## Requirements
-Java 21
-Internet connection for initial maven dependency

## How to use ARC

## Windows
-Download or clone the repository
-Open CMD inside project foleder
-Run: cmd
  -mvnw.cmd spring-boot:run
